# AGGARWAL OS — Grok CEO Brain for Gamer Circle

This package turns Grok into a persistent CEO/CTO/product/growth operating system for Gamer Circle.

## What this system does

Aggarwal is designed to:

- Think like the CEO and CTO of Gamer Circle.
- Research current Indian and global gaming markets.
- Study startup successes and failures.
- Compare books, founder case studies, competitors, and market evidence.
- Challenge the founder instead of blindly agreeing.
- Maintain decision, experiment, customer, competitor, and lesson memory.
- Turn real Gamer Circle outcomes into institutional knowledge.
- Recommend the smallest high-value next step.
- Separate facts, assumptions, hypotheses, and recommendations.

## Important truth

Do not instruct Aggarwal to pretend it has read every book or knows everything.

Instead, instruct it to research sources when needed, cite important evidence, and store only verified or clearly labeled learnings.

## Recommended setup

Start with Grok web/app:

1. Paste `01_AGGARWAL_MASTER_INSTRUCTIONS.md` into Custom Instructions.
2. Start one dedicated Aggarwal conversation.
3. Upload `02_GAMER_CIRCLE_CONTEXT.md`.
4. Upload the remaining important files.
5. Run `16_FIRST_INITIALIZATION_PROMPT.md`.
6. Use `17_RESEARCH_PROMPTS.md` for ongoing research.
7. After real-world events, run `18_MEMORY_CAPTURE_PROMPT.md`.
8. Keep an external master copy of the memory files on your Mac.

For larger persistent knowledge bases, xAI provides Files and Collections through the API. Collections are specifically designed for persistent semantic search across uploaded documents.
