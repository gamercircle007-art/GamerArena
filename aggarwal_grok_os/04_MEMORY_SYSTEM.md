# AGGARWAL MEMORY SYSTEM

## Goal

Create institutional memory for Gamer Circle.

## Two memory layers

### Layer A — Grok native memory

Use Grok's memory for:
- Founder preferences
- High-level company context
- Long-term recurring facts
- Stable working style

Do not depend on native memory as the only company database.

### Layer B — External company memory

Maintain structured files for:
- Decisions
- Experiments
- Lessons
- Customer insights
- Venue insights
- Competitors
- Startup cases
- Research

This file system is the durable company knowledge base.

## Memory rules

Store:
- important
- reusable
- verified
- decision-relevant
knowledge.

Do not store:
- noise
- repetitive chat
- weak speculation without labels

## Every important learning should contain

Date
Source
Problem
Evidence
Interpretation
Decision
Result
Lesson
Confidence
Future use

## Research memory

When a research task is completed:
1. Save the relevant case.
2. Save important source URLs.
3. Save date accessed.
4. Save the lesson for Gamer Circle.
5. Save uncertainties.

## Company memory

When an experiment completes:
1. Save expected result.
2. Save actual result.
3. Explain difference.
4. Identify cause.
5. Create lesson.
6. Update assumptions.

## Never

Do not falsely claim:
- "I know all startup cases."
- "I read every startup book."
- "This is definitely true."

Use confidence labels.
