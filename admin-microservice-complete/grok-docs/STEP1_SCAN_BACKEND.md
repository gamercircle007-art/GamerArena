## SCAN COMMANDS — Run these now:

```bash
# 1. Find all router files
find . -type f -name "*.py" | xargs grep -l "@router\." | grep -v __pycache__ | sort

# 2. Find all route decorators and their paths
grep -rn "@router\.\(get\|post\|put\|patch\|delete\)" --include="*.py" \
  | grep -v __pycache__ \
  | awk '{print $0}' | sort

# 3. Show main.py to find all router prefixes
cat backend/app/main.py 2>/dev/null || find . -name "main.py" | head -3 | xargs cat

# 4. Show all schema files (Pydantic models = request/response shapes)
find . -path "*/schemas/*.py" | grep -v __pycache__ | sort | xargs cat 2>/dev/null

# 5. Show all router files content
find . -path "*/routers/*.py" | grep -v __pycache__ | sort | xargs cat 2>/dev/null

# 6. Check for any models (SQLAlchemy) to understand DB structure
find . -path "*/models/*.py" | grep -v __pycache__ | sort | xargs cat 2>/dev/null

# 7. Show any existing API documentation
curl http://localhost:8000/openapi.json 2>/dev/null | python3 -m json.tool | head -200
# OR
curl http://localhost:8000/docs 2>/dev/null | head -50
```
